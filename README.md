# My Own Decor — Static Website Starter

A premium, responsive five-page interior design website built with HTML5, CSS3, Bootstrap 5 and vanilla JavaScript.

## Pages
- `index.html` — Home
- `about.html` — About the studio
- `services.html` — Services
- `projects.html` — Portfolio with category filters
- `contact.html` — Contact details and demo enquiry form

## Run locally
1. Extract the ZIP file.
2. Open the `interior-design-website` folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the **Live Server** extension in VS Code.

No Node.js, database or backend is required.

## Before publishing — important customisation
Search the project for `My Own Decor`, `MY OWN DECOR`, and `myowndecor.example`, then replace:
- Brand name and logo text
- Email address and phone / WhatsApp number
- Location and company story
- Service descriptions
- Sample project titles and images

The photographs currently use remote Unsplash image URLs, so an internet connection is required to display them. Replace them with your own licensed project photos before launch. The project gallery currently contains illustrative inspiration images, not verified client projects.

## Contact form
The contact form is front-end only. It validates required fields and opens the visitor's default email application using a `mailto:` link. For direct website submissions, connect a form provider (for example, Formspree or Netlify Forms) or build a backend API.

## Deployment
This project can be hosted on GitHub Pages, Netlify or Cloudflare Pages. Upload the contents of this folder, keeping the `css` and `js` folders in place.

## Technologies
- Bootstrap 5.3.3 (CDN)
- Google Fonts (CDN)
- Vanilla JavaScript
- Unsplash image URLs (remote)


## Brand
The starter brand is **My Own Decor**. Update the logo text, brand story, email, phone number and location before publishing.
